# 1. Что должно быть установлено (0–5 мин)

| Инструмент | Версия | Проверка |
|---|---|---|
| Git | 2.40+ | `git --version` |
| .NET SDK | **9.0** | `dotnet --version` |
| Node.js | 20 LTS+ (22/24) | `node -v` |
| PostgreSQL | **15+** | `psql -V` |
| DBeaver | 24+ | графическая проверка |
| VS Code или Rider | — | редактор |
| Postman | 10+ | проверка API |
| git.scc | 3.x | подсчёт строк в коде |

> **Замечание:** версии из инфраструктурного листа чемпионата 2026 — РедОС 8.0,
> .NET 9.0, Node.js 22.14, Git 2.48, DBeaver 25, Postman 7.33, Rider 2024.3,
> WebStorm 2024.3, Android Studio 2024.3.1 + Android 10 SDK. Ставьте максимально
> близко к этому списку: на площадке установят именно эти версии.

# 2. .NET SDK 9 (5–8 мин)

**Windows:**

```bash
winget install Microsoft.DotNet.SDK.9
```

**РедОС 8.0:**

```bash
sudo dnf install -y dotnet-sdk-9.0
```

Проверка — должно быть `9.0.xxx`, не `8.0`:

```bash
dotnet --list-sdks
dotnet --version
```

> **Замечание:** на РедОС `dotnet` может не оказаться в `PATH`. Добавьте
> `export PATH=$PATH:/usr/lib64/dotnet` и `$HOME/.dotnet` в `~/.bashrc`.

# 3. Node.js (8–10 мин)

**Windows:**

```bash
winget install OpenJS.NodeJS.LTS
```

**РедОС 8.0:**

```bash
sudo dnf module disable -y nodejs
sudo dnf install -y nodejs
```

Проверка:

```bash
node -v
npm -v
```

# 4. PostgreSQL (10–13 мин)

### Windows

```bash
winget install PostgreSQL.PostgreSQL.16
```

Установщик спросит пароль суперпользователя — запомните его, он пойдёт в строку
подключения. В `Installation Wizard` отметьте **Command Line Utilities**,
иначе `psql` не появится в PATH.

### РедОС 8.0

```bash
sudo dnf install -y postgresql-server postgresql-contrib
sudo postgresql-setup --initdb || true
sudo systemctl enable --now postgresql
```

Создание роли и базы данных (команда от пользователя `postgres`):

```bash
sudo -u postgres psql -c "CREATE ROLE taskplanner LOGIN PASSWORD 'taskplanner' CREATEDB;"
sudo -u postgres psql -c "CREATE DATABASE taskplanner OWNER taskplanner;"
```

Разрешить вход по паролю — откройте `/var/lib/pgsql/data/pg_hba.conf` и для
локальных подключений оставьте парольную аутентификацию:

```
local   all   all                  peer
local   all   all                  scram-sha-256
host    all   all   127.0.0.1/32   scram-sha-256
host    all   all   ::1/128        scram-sha-256
```

```bash
sudo systemctl restart postgresql
```

> **Замечание:** на площадке **нет Docker** в списке оснащения, поэтому
> PostgreSQL ставится нативно. `docker-compose.yml` можно держать в репозитории
> как удобную опцию для Windows, но решение не должно зависеть от него.

Проверка подключения:

```bash
psql -h 127.0.0.1 -U taskplanner -d taskplanner -c "SELECT version();"
```

# 5. DBeaver и git.scc (13–15 мин)

**DBeaver** — скачивается с [dbeaver.io](https://dbeaver.io/download/).
Создайте подключение PostgreSQL:

```
Host:     127.0.0.1
Port:     5432
Database: taskplanner
User:     taskplanner
Password: taskplanner
```

`Test Connection` → OK. Обновите драйвер: в настройках подключения
`Download` → выберите PostgreSQL JDBC Driver → `Apply`.

**git.scc** — считает строки кода по языкам, пригодится для раздела
«Документирование»:

```bash
# macOS / Linux
brew install git-scc
# или
go install github.com/boyter/scc/v3/cmd/scc@latest

# Windows — скачать релиз
# https://github.com/boyter/scc/releases
```

```bash
scc --version
```

# Проверка

Все команды должны отработать без ошибок:

```bash
git --version
dotnet --version
node -v
psql -V
scc --version
```

# Если что-то не получилось

| Симптом | Что делать |
|---|---|
| `dotnet: command not found` | переустановить SDK 9, добавить в `PATH`, открыть новый терминал |
| версия .NET 8 вместо 9 | поставить SDK 9 рядом со старым: `dotnet --list-sdks` покажет оба |
| `psql: command not found` | переустановить с компонентом Command Line Utilities |
| `could not translate host name` | проверить, запущен ли сервер: `systemctl status postgresql` |
| `scc: command not found` | поставить через `go install` или скачать релиз вручную |
