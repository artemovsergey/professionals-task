Сессия 0. Репозиторий и структура · 15–100 мин

# Что делаем на этой странице

Создаём репозиторий, кладём `.gitignore`, заводим ветку и раскладываем
заготовки по папкам. Дальше каждая сессия добавляет код в свою папку, и
структура не рассыпается.

# Шаг 1. Репозиторий и первый коммит

```bash
git clone https://github.com/<ваш-логин>/professionals-task.git
cd professionals-task
git status
```

`git status` должен быть чистым — если нет, проверьте, что клонировался
нужный репозиторий.

# Шаг 2. Ветка на работу

```bash
git switch -c feat/backend
```

Работа идёт в ветке, а не в `master`: так видно историю по этапам и можно
вернуться к рабочему состоянию в любой момент. `master` обновляется только
проверенным кодом.

```bash
git branch          # список веток
git log --oneline   # что уже есть
```

# Шаг 3. `.gitignore`

Файл нужен сразу, до первой установки пакетов: иначе в первый коммит
попадут сотни мегабайт `node_modules`.

```gitignore
# секреты и локальные настройки
.env
.env.*
!.env.example

# зависимости и сборка
node_modules/
web/node_modules
mobile/node_modules
web/dist
mobile/dist
api/*/bin
api/*/obj
.nuget/
```

![[images/setup01-s1-gitignore.png]]
*.gitignore: секреты, зависимости и артефакты сборки не попадут в коммит*

Проверьте, что игнор работает, до первого коммита:

```bash
git status --short
```

В списке не должно быть ни `node_modules`, ни `bin`, ни `obj`.

# Шаг 4. Структура репозитория

```bash
mkdir -p \
  db/erd \
  docs/api docs/testcases docs/uml docs/screenshots \
  postman \
  src/api/TaskPlanner.Api src/api/TaskPlanner.Core src/api/TaskPlanner.Tests \
  src/web src/desktop/TaskPlanner.Desktop src/mobile
```

В каждой пустой папке кладётся `README.md` в одну строку — Git не хранит
пустые каталоги, и без файла структура «исчезнет» после клонирования:

```bash
printf 'Backend: ASP.NET Core Web API (.NET 9)\n' > src/api/TaskPlanner.Api/README.md
printf 'Доменный слой: сущности, DTO, сервисы\n'     > src/api/TaskPlanner.Core/README.md
printf 'Тесты xUnit\n'                                > src/api/TaskPlanner.Tests/README.md
printf 'Web-клиент: React + Vite\n'                  > src/web/README.md
printf 'Desktop-клиент: Avalonia 11 (MVVM)\n'         > src/desktop/TaskPlanner.Desktop/README.md
printf 'Mobile-клиент: React Native\n'                > src/mobile/README.md
```

# Шаг 6. Первый коммит

```bash
git add .gitignore src/*/README.md
git commit -m "Репозиторий: gitignore и структура проекта"
git log --oneline
```

# Проверка

```bash
git status --short          # пусто
git branch --show-current   # ваша ветка, не master
find . -name node_modules -prune -o -type f -print | head -20
```

# Коммит

```bash
git add . && git commit -m "Репозиторий: gitignore, структура и заготовки клиентов"
```

# Если что-то не получилось

| Симптом | Что делать |
|---|---|
| `node_modules` в `git status` | правило в `.gitignore` не сработало — проверьте, что имя без ведущего `/` |
| Каталог пропал после клонирования | положите в него `README.md`, Git не хранит пустые папки |
| `.env` попал в коммит | добавьте правило и удалите из индекса: `git rm --cached .env` |
| `git switch: command not found` | Git старше 2.23 — используйте `git checkout -b` |
| Файлы помечены как изменённые без правок | проблема с переносом строк: `git config core.autocrlf false` |
