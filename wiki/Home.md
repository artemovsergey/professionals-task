**Компетенция:** Программные решения для бизнеса · Чемпионат «Профессионалы» 2027

Задание разобрано **по спринтам**: 24 спринта, 54 страницы, каждая страница — 2–3 часа работы.

## Как устроен тренинг

| Параметр | Значение |
|---|---|
| Всего спринтов | **24** |
| Всего страниц | **54** |
| Длина страницы | **2–3 часа** |
| Результат сессии | рабочий код в репозитории + коммит |

Проходите страницы по порядку. Страница заканчивается коммитом, даже если что-то не успели: незавершённый код полезнее, чем ничего.

> **Не застревайте.** Если блок не получается за 20–25 минут — переходите по таблице «Если что-то не получилось» и возвращайтесь на следующей сессии.

## Важные правила

1. **Целевая ОС — РедОС 8.0.** Никаких Windows-путей, обратных слэшей, `cmd` и PowerShell. Команды в wiki — только bash.
2. **PostgreSQL ставится нативно** через `dnf`; Docker на площадке может отсутствовать.
3. **ИИ запрещён** для кода, SQL, триггеров, функций, архитектуры БД и тестов. Разрешён только для текстов документации и презентации, и только в браузере без авторизации.
4. **Формат ответа API единый:** `{ "success", "data", "message", "error_code" }` — см. [13-Формат-ответа-и-обработка-ошибок](13-Формат-ответа-и-обработка-ошибок).
5. **Номер заявки** формируется автоматически в формате `Z-YYYY-XXXX` — см. [19-Генерация-номера-заявки](19-Генерация-номера-заявки).
