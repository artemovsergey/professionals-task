# Отбор на чемпионат «Профессионалы» — пошаговая инструкция

**Компетенция:** Программные решения для бизнеса
**Задание:** [планировщик личных задач](https://github.com/artemovsergey/professionals-task/blob/main/ЗАДАНИЕ.md)

Задание уже сделано за вас — здесь оно разобрано по шагам, с готовым кодом.
Ваша задача — пройти страницы по порядку и получить работающее решение у себя
в репозитории.

---

## Как устроен тренинг

| Параметр | Значение |
|---|---|
| Длина одной сессии | **2 часа 30 минут** |
| Всего сессий | **10** |
| Общее время | **25 часов** |
| Страниц в wiki | 28 |
| Результат сессии | рабочий код в репозитории + коммит |

Сессия заканчивается коммитом, даже если что-то не успели. Незавершённый код
в репозитории полезнее, чем ничего: на следующей сессии вы продолжите с того
же места.

> **Не застревайте.** Если блок не получается за 20–25 минут — идите дальше по
> инструкции «что делать, если не получилось» (в конце каждой страницы такой
> блок есть) и возвращайтесь на следующей сессии.

## Где лежит API

Все клиенты работают с **одним** сервером. Отдельных бэкендов не нужно.

| Клиент | Адрес API при разработке |
|---|---|
| Web (Vite) | `http://localhost:5000` через прокси Vite `/api` |
| Desktop (Avalonia) | `http://localhost:5000` |
| Mobile (React Native) | `http://localhost:5000` (Android: `http://10.0.2.2:5000`) |

Единая обёртка ответа — **везде одинаковая**:

```json
{ "success": true,  "data": { }, "message": "OK",                   "error_code": null }
{ "success": false, "data": null,   "message": "Задача не найдена",  "error_code": "NOT_FOUND" }
```

Спецификация: [`api/openapi.yaml`](https://github.com/artemovsergey/professionals-task/blob/main/api/openapi.yaml) —
если сомневаетесь в именах полей, откройте его, а не выдумывайте свои.

## Про РедОС

На площадке чемпионата основная ОС — **РедОС 8.0**. Отбор можно проходить на
Windows, но код обязан запускаться на РедОС:

- никаких Windows-путей (`C:\`) и обратных слэшей в путях;
- никаких `cmd`/`PowerShell`-команд в инструкциях и скриптах;
- PostgreSQL ставится нативно через `dnf` (на площадке может не быть Docker);
- `dotnet`, `node`, `psql` работают из терминала без перезагрузки — настройте
  `PATH`.

> **Замечание:** если вы работаете на Windows — выполняйте команды в
> **Git Bash**, а не в PowerShell. Инструкции в wiki написаны под Git Bash,
> и на РедОС они выполняются как есть.
