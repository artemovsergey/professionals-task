# Шаг 1. Чистая база

```bash
dropdb -h 127.0.0.1 -U taskplanner taskplanner 2>/dev/null
createdb -h 127.0.0.1 -U taskplanner taskplanner
psql -h 127.0.0.1 -U taskplanner -d taskplanner -f db/schema.sql
psql -h 127.0.0.1 -U taskplanner -d taskplanner -f db/seed.sql
```

Проверяйте с чистой базы, а не с той, в которой вы работали полдня:
ошибка в `schema.sql` иначе не проявится — у вас в базе таблицы уже есть.

# Шаг 4. Три клиента видят одно и то же

| Клиент | Что проверить |
|---|---|
| Web | вход → список → фильтр «Выполненные» → создание задачи → сводка |
| Desktop | вход → список → отметка выполнения → сводка |
| Mobile | вход → список → создание задачи → фильтр |

Ключевая проверка одна: задача, созданная в web, появляется в desktop и
mobile. Если нет — клиенты ходят не в тот API или у каждого своя база.

```bash
curl -s http://localhost:5080/api/tasks/summary -H "Authorization: Bearer $TOKEN"
```

Цифры сводки должны совпадать с тем, что показывает каждый клиент.

# Шаг 6. Чистота репозитория

```bash
git status --short
git ls-files | grep -E "\.(bin|exe|dll|log|user)$|node_modules|/obj/|\.db$|\.dump$"
```

Второй вывод должен быть пустым.

```bash
git grep -nI "eyJhbGciOi"                              # JWT-токены в коде
git log --all --oneline -- .env                        # .env в истории
```

Если токен попал в репозиторий — отмените коммит и выпустите новый.
Переписывать историю на отборе не нужно: главное, чтобы секрета не было
в текущей версии.

# Шаг 7. Финальный коммит

```bash
git add -A
git commit -m "Итог: полное решение задания, документация и тесты"
git log --oneline --graph | head -30
```

В истории должно быть видно последовательные коммиты по частям. Это
подтверждает, что работа шла итерациями, а не была сгенерирована за час.

# Шаг 8. Проверка на РедОС

Отдельным заходом после сдачи. Основная ОС на площадке — РедОС 8.0, и
именно на ней запускается проверка:

```bash
dotnet --version      # 9.0
node --version        # 20+
dotnet build          # без ошибок
npm run build         # без ошибок
```

Если что-то не собралось на РедОС — запишите точный текст ошибки в README
и приложите проверенный вариант на Windows. Это честнее, чем молчание.

# Если что-то не получилось

| Симптом | Что делать |
|---|---|
| Тесты падают с `401` | не поднят API или в `appsettings.json` другой ключ JWT |
| В web есть задачи, в desktop нет | клиент обращается к другому адресу — сверьте `BaseUrl` и прокси |
| `git ls-files` показывает мусор | файлы уже в индексе: `git rm --cached -r <путь>` и допишите правило в `.gitignore` |
| В логе один огромный коммит | переписывать историю не нужно; новые коммиты по частям сделают её читаемой |
| На РедОС не собирается Avalonia | сверьте версию .NET: нужна 9.0, см. [00-Подготовка-окружения](00-Подготовка-окружения) |
