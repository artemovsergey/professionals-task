## Шаг 1. Универсальная таблица — 30 мин

Одна таблица на все три реестра: колонки, строки, сортировка, пагинация, состояние загрузки и пустоты. Отличаются только описания колонок.

**src/web/src/components/DataTable.tsx**

```typescript
export interface Column<T> {
  key: keyof T & string;
  title: string;
  render?: (row: T) => ReactNode;
  width?: number;
  align?: 'left' | 'center' | 'right';
}

export function DataTable<T extends { id: string }>({ columns, rows, total, page, size, onPage }: Props<T>) {
  return (
    <div className="data-table">
      <table>
        <thead><tr>{columns.map((c) => <th key={c.key} style={{ width: c.width, textAlign: c.align }}>{c.title}</th>)}</tr></thead>
        <tbody>{rows.map((row) => <tr key={row.id}>{columns.map((c) =>
          <td key={c.key} style={{ textAlign: c.align }}>{c.render ? c.render(row) : String(row[c.key])}</td>)}</tr>)}</tbody>
      </table>
      <Pagination total={total} page={page} size={size} onChange={onPage} />
    </div>
  );
}
```

> **Замечание.** Дженерик с ограничением `T extends { id: string }` — минимальный контракт, который гарантирует ключи React. Без него таблица будет дублировать строки при перерисовке.


## Шаг 2. Реестр оборудования — 30 мин

Колонки: инвентарный номер, наименование, цех, вид, статус, критичность, дата ввода. Фильтры: цех, статус, критичность. Действия — просмотр и правка.

```typescript
const EQUIPMENT_COLUMNS: Column<EquipmentDto>[] = [
  { key: 'inventoryNumber', title: 'Инв. №', width: 130 },
  { key: 'name', title: 'Наименование' },
  { key: 'workshopName', title: 'Цех', width: 160 },
  { key: 'status', title: 'Статус', width: 200, render: (r) => <StatusBadge status={r.status} /> },
  { key: 'criticality', title: 'Критичность', width: 140, align: 'center' },
  { key: 'commissionDate', title: 'Введено', width: 130, align: 'right' },
];

export default function EquipmentPage() {
  const [page, setPage] = useState(1);
  const [query, setQuery] = useState('');
  const { rows, total } = usePaged<EquipmentDto>('/api/equipment', { page, size: 12, search: query });
  return <DataTable columns={EQUIPMENT_COLUMNS} rows={rows} total={total} page={page} size={12} onPage={setPage} />;
```

> **Замечание.** Статус «Выведено из эксплуатации» рендерите серым и не давайте менять его вручную: сервер всё равно отклонит правку триггером, а клиент должен предупреждать заранее.

Колонки: номер, оборудование, приоритет, статус, бригада, простой. Фильтры: статус, приоритет, период. Номер заявки — ссылка на карточку.

```typescript
const WORK_ORDER_COLUMNS: Column<WorkOrderDto>[] = [
  { key: 'number', title: 'Номер', width: 130,

  { key: 'equipmentName', title: 'Оборудование' },
  { key: 'priority', title: 'Приоритет', width: 130,

  { key: 'status', title: 'Статус', width: 140, render: (r) => <StatusBadge status={r.status} /> },
  { key: 'crewName', title: 'Бригада', width: 160, render: (r) => r.crewName ?? '—' },
  { key: 'downtimeHours', title: 'Простой', width: 120, align: 'right',
```

> **Замечание.** Для `null` пишите «—», а не `0`. Отличие «простоя не было» и «простоя 0 ч» видно эксперту и вливается в отчёт.


## Шаг 4. График планового ТО — 30 мин

Календарная сетка по месяцам с цветовой полосой по видам обслуживания. Клик по дню открывает карточку записи графика.

**src/web/src/pages/SchedulePage.tsx**

```typescript
export function SchedulePage() {
  const [month, setMonth] = useState(startOfMonth(new Date()));
  const { rows } = useApi<ScheduleItem[]>('/api/maintenance-schedule', {
    from: startOfMonth(month).toISOString().slice(0, 10),
    to: endOfMonth(month).toISOString().slice(0, 10),
  });
  const byDay = useMemo(() => groupBy(rows, (r) => r.plannedDate), [rows]);
  return (
    <div className="schedule-grid">
      {eachDayOfInterval({ start: startOfMonth(month), end: endOfMonth(month) }).map((day) => (
        <div key={day.toISOString()} className="day" data-empty={!byDay[format(day, 'yyyy-MM-dd')]}>
          <span className="day-number">{format(day, 'd')}</span>
          {(byDay[format(day, 'yyyy-MM-dd')] ?? []).map((item) => (
            <button key={item.id} className="plan-chip">{item.maintenanceTypeName}</button>
          ))}
        </div>
      ))}
    </div>
  );
}
```

> **Замечание.** Пустые дни не удаляйте — оставьте ячейки с `data-empty`, иначе календарь «схлопнется» и месяц перестанет читаться.


## Если что-то не получилось

| Симптом | Что делать |
|---|---|
| При смене страницы остаются старые строки | забыли сбросить `page` в 1 при смене фильтра |
| Ключи React дублируются | в `DataTable` нет ограничения `T extends { id: string }` |
| Простой показан нулём у незавершённых заявок | не обработан `null` в рендере |
| Календарь сжимается | пустые дни не отрисованы |
