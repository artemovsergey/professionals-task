Сессия 3. Web-клиент: форма задачи · 70–95 мин

# Что делаем на этой странице

Одна форма работает в двух режимах: создание задачи и правка существующей.
Различия — только в заголовке и в том, какая задача пришла в компонент.

# Шаг 1. Состояние формы

`src/components/TaskForm.jsx`:

```javascript
export default function TaskForm({ task, onSave, onCancel }) {
  const [title, setTitle] = useState(task?.title ?? '');
  const [description, setDescription] = useState(task?.description ?? '');
  const [status, setStatus] = useState(task?.status ?? 'new');
  const [priority, setPriority] = useState(task?.priority ?? 'medium');
  const [dueDate, setDueDate] = useState(task?.dueDate ?? '');
  const [error, setError] = useState('');
```

Опциональная цепочка `task?.title ?? ''` делает две вещи сразу: при создании
`task` равен `undefined`, и поля пустые; при правке берутся значения задачи.
Отдельных компонентов для создания и правки не нужно.

![[images/web17-s1-state.png]]
*Пять полей и текст ошибки — всё состояние формы в одном месте*

# Шаг 2. Сохранение

```javascript
const submit = async (event) => {
  event.preventDefault();
  try {
    await onSave({
      title,
      description: description || null,
      status,
      priority,
      dueDate: dueDate || null,
    });
  } catch (e) {
    setError(e.message);
  }
};
```

Две детали:

- пустые строки уходят как `null`, а не `""` — сервер различает «не задано»
  и «задано пустым значением»;
- `catch` ловит ошибку API и кладёт её текст в состояние. Форма не падает и
  не закрывается: пользователь видит, что именно не так, и может исправить.

![[images/web17-s2-submit.png]]
*Форма сама превращает ошибку сервера в текст на экране*

# Шаг 3. Поля

```jsx
<div className="field">
  <label htmlFor="title">Название</label>
  <input id="title" value={title} onChange={(e) => setTitle(e.target.value)} required />
</div>
<div className="field">
  <label htmlFor="description">Описание</label>
  <textarea id="description" value={description} onChange={(e) => setDescription(e.target.value)} />
</div>
```

У поля есть `id`, а у подписи — `htmlFor`: без этого клик по слову
«Название» не переводит фокус в поле, и такой мелочью на отборе часто
снимают баллы за доступность.

Атрибут `required` работает как первая линия проверки, но не заменяет сервер:
в браузере его легко обойти, и API всё равно должен отвечать `400`.

![[images/web17-s3-fields.png]]
*Каждое поле связано с подписью, у названия включена браузерная проверка*

# Шаг 4. Что происходит после сохранения

`src/components/TaskBoard.jsx`:

```javascript
const save = async (task) => {
  if (editing) {
    await api.updateTask(editing.id, task);
  } else {
    await api.createTask(task);
  }
  setEditing(null);
  await load();
};
```

Одна функция обслуживает оба режима: если открытая задача известна — `PUT`,
иначе `POST`. После сохранения форма закрывается, а список перечитывается с
сервера. Не обновляйте список локально из ответа: пагинация и счётчики
пересчитаются по-настоящему только новым запросом.

![[images/web17-s4-save-handler.png]]
*Режим выбирается по наличию открытой задачи*

# Проверка

| Проверка | Ожидание |
|---|---|
| «Новая задача» | пустая форма со значениями по умолчанию |
| название из пробелов | `Проверьте поля: title` |
| название длиннее 200 | та же ошибка, поле `title` |
| сохранение корректной задачи | форма закрылась, счётчик вырос |
| «Изменить» | поля заполнены текущими значениями |
| «Отмена» | ничего не изменилось, запрос не уходил |
| «Удалить» | задачи нет, счётчик уменьшился |
| клик по подписи поля | фокус в поле |

# Если что-то не получилось

| Симптом | Что делать |
|---|---|
| Форма не открывается | проверьте состояние `editing` и условный рендеринг |
| При правке поля пустые | в компонент не передана задача: `task?.title ?? ''` |
| Ошибка сервера не видна | в `catch` нет `setError(e.message)`, либо рядом `{error ? ... }` |
| Форма закрывается даже при ошибке | `onSave` вызывается без `await`, и `catch` не успевает отработать |
| Пустые строки приходят как `""` | забыли `|| null` при сборке объекта |
| Задача сохраняется дважды | форма отправляется и по кнопке, и по `onSubmit` без `preventDefault` |
| Кнопка «Отмена» отправляет запрос | кнопка внутри `<form>` без `type="button"` |
| Удаление не обновляет список | после удаления не перечитывается `load()` |
