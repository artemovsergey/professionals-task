# 27. Оболочка навигация и авторизация

> Спринт 12. Desktop: каркас, навигация, авторизация · 150 мин · страница 27 из 54

Собираем оболочку приложения: экран входа, боковое меню, верхняя панель, хлебные крошки и автоблокировку по бездействию. Эти элементы — общие требования задания, они считаются один раз на всё приложение.

**Итог страницы.** Приложение открывается экраном входа, после входа — с боковым меню и верхней панелью; бездействие 15 секунд возвращает на экран входа.

## Шаг 1. Экран входа — 35 мин

Форма с логином, паролем и кнопкой. Ошибка неверного пароля приходит из API кодом 401 и показывается под полем, а не в модальном окне.

**src/desktop/Views/LoginView.axaml**

```xml
<StackPanel Spacing="12" Width="360">
  <TextBlock Text="ТОиР-Проф" FontSize="28" FontWeight="Bold" HorizontalAlignment="Center" />
  <TextBox Watermark="Логин" Text="{Binding Login}" />
  <TextBox Watermark="Пароль" PasswordChar="•" Text="{Binding Password}" KeyDown="OnPasswordKeyDown" />
  <TextBlock Text="{Binding ErrorMessage}" Foreground="#C62828" TextWrapping="Wrap" />
  <Button Content="Войти" Command="{Binding LoginCommand}" IsEnabled="{Binding !IsBusy}" HorizontalAlignment="Stretch" />
</StackPanel>
```

> **Замечание.** Enter в поле пароля должен вызывать ту же команду, что и кнопка. Мастер вводит пароль десятки раз за смену — каждый раз тянуться мышью к кнопке раздражает.


## Шаг 2. Боковое меню и верхняя панель — 35 мин

Меню строится по ролям: мастеру не показываем пользователей и справочники, руководителю — всё.

**src/desktop/ViewModels/MainWindowViewModel.cs**

```csharp
private IReadOnlyList<NavItem> BuildMenu(string role) => role switch
{
    "MASTER" => new[]
    {
        new NavItem("Дашборд", "/dashboard"),
        new NavItem("Оборудование", "/equipment"),
        new NavItem("График ТО", "/schedule"),
        new NavItem("Заявки", "/work-orders"),
        new NavItem("Отчёты", "/reports"),
    },
    _ => new[]
    {
        new NavItem("Дашборд", "/dashboard"),
        new NavItem("Аналитика", "/analytics"),
        new NavItem("Пользователи", "/users"),
    }
};
```

> **Замечание.** Меню скрывает пункты, а не отключает их. Права проверяются ещё и на сервере, но скрытие экономит время: пользователь не кликает по заведомо недоступному пункту.


## Шаг 3. Хлебные крошки — 25 мин

Верхняя цепочка показывает путь «Цех / Оборудование / Станок ТА-16» и работает как навигация.

**src/desktop/Views/MainWindow.axaml**

```xml
<ItemsControl ItemsSource="{Binding Breadcrumbs}">
  <ItemsControl.ItemsPanel>
    <ItemsPanelTemplate><StackPanel Orientation="Horizontal" /></ItemsPanelTemplate>
  </ItemsControl.ItemsPanel>
  <ItemsControl.ItemTemplate>
    <DataTemplate>
      <StackPanel Orientation="Horizontal">
        <TextBlock Text="{Binding Title}" Classes="crumb" />
        <TextBlock Text="/" Margin="6,0" Opacity="0.5" />
      </StackPanel>
    </DataTemplate>
  </ItemsControl.ItemTemplate>
</ItemsControl>
```

> **Замечание.** Последний элемент цепочки — не ссылка. Иначе пользователь бесконечно «возвращается» на ту же страницу.


## Шаг 4. Автоблокировка по бездействию — 30 мин

Таймер считает секунды с последнего ввода. Порог 15 секунд задан в задании и не меняется — эксперты проверяют именно его.

**src/desktop/Views/MainWindow.axaml.cs**

```csharp
private readonly DispatcherTimer _idleTimer = new() { Interval = TimeSpan.FromSeconds(1) };
private DateTime _lastInput = DateTime.UtcNow;

private void OnAnyInput(object? sender, InputEventArgs e) => _lastInput = DateTime.UtcNow;

private void OnIdleTick(object? sender, EventArgs e)
{
    if ((DateTime.UtcNow - _lastInput).TotalSeconds < 15) return;
    _idleTimer.Stop();
    _auth.Logout();
    CurrentView = _loginViewModel;
}
```

> **Замечание.** Подписаться на ввод нужно на корневом элементе окна: события мыши и клавиатуры всплывают к нему от вложенных контролов. Подписка на каждом экране отдельно приводит к тому, что форма без своего обработчика не сбрасывает таймер.


## Шаг 5. Хранилище токена — 25 мин

Токен кладём в защищённое хранилище операционной системы, а не в обычный текстовый файл.

**src/desktop/Services/TokenStorage.cs**

```csharp
public interface ITokenStorage
{
    void Save(string accessToken, string refreshToken, string role);
    (string Token, string Role)? Load();
    void Clear();
}

public sealed class KeychainTokenStorage : ITokenStorage
{
    public void Save(string accessToken, string refreshToken, string role) { /* libsecret / DPAPI */ }
    public (string, string)? Load() { /* читаем из хранилища */ }
    public void Clear() { /* удаляем записи */ }
}
```

> **Замечание.** Простой текстовый файл рядом с exe — это утечка при любой проверке. Достаточно реализовать интерфейс поверх Windows DPAPI и Linux libsecret, а если библиотеки нет — хотя бы `Environment.SpecialFolder.LocalApplicationData` с правами 600.


## Если что-то не получилось

| Симптом | Что делать |
|---|---|
| Кнопка «Войти» не реагирует | нет привязки `Command` или обработчик Enter не вызывает ту же команду |
| Меню показывает лишние пункты | роль читается не из токена, а из локальной переменной |
| Автоблокировка не срабатывает | подписка на ввод сделана на конкретном экране, а не на окне |
| После выхода остаётся токен | `Logout()` вызывает `Clear()` хранилища |
