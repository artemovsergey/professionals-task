# Постеры отбора

Три готовых варианта 1080×1350. Текст, QR-код и логотипы одинаковые —
различаются только фон, палитра и композиция.

| Файл | Вариант | Фон | Цвета |
|---|---|---|---|
| `poster.png` | основной | фото антенны во весь постер | `#0F9346` / `#364046` |
| `poster-variant-a.png` | A «плакат» | фирменный чёрный + кубы и шевроны | `#1D1D1B` / `#4ECC0A` |
| `poster-variant-b.png` | B «инверсия» | фирменный зелёный + кубы и шевроны | `#4ECC0A` / `#1D1D1B` |

## Что где лежит

| Файл | Назначение |

## Палитра бренда

Текст из `assets/Брендбук_2026.pdf` вытащить не удалось: это экспорт из
Figma, шрифты в подмножествах с CID-кодировкой. Поэтому значения сняты
пипеткой с самих знаков:

```
assets/professionals_logo_02-1.png → #4ECC0A (31k px), #1D1D1B (11k px)
assets/professionals_logo_02-3.png → шкала #1D1D1B → #398411 → #4ECC0A
assets/chevrons.svg               → заливка #4ECC0A
```

Бренд держится на двух цветах — ярко-зелёном и почти чёрном. Цвета
`#0F9346` и `#364046`, которые остались в основном постере, — это палитра
**колледжа**, а не чемпионата.

## Перегенерация

Шрифты грузятся из сети, поэтому из `file://` картинка не соберётся —
нужен локальный сервер:

```bash
cd ..                      # корень репозитория
python3 -m http.server 8900
```

Отдельный рендер каждого варианта:

```bash
google-chrome --headless=new --force-device-scale-factor=1 \
  --window-size=1080,1350 --hide-scrollbars --virtual-time-budget=8000 \
  --user-data-dir=/tmp/chrome-poster --screenshot=post/poster.png \
  "http://127.0.0.1:8900/post/poster.html"
```

Для вариантов A и B подставьте свой файл на входе и свой путь на выходе.

## Правила, общие для всех вариантов

- QR-код ведёт на репозиторий: `assets/qr_repo.png`. Не заменяйте,
  пока адрес репозитория не менялся.
- Ссылок на сайт в тексте постера нет — адрес уже внутри QR.
- Описания задания на постер нет: постер зовёт, а условия отдаёт по ссылке.
- Поле года в знаке (`«ПОЛЕ ДЛЯ ВВОДА ГОДА»`) — заготовка брендбука.
  Оно закрывается плашкой с годом: в знаке 1218×450 рамка занимает
  x 45.2–61.2%, y 4.0–19.1%. Плашка берёт границы с запасом ~5 px,
  иначе пунктир торчит за её края.
- Фон антенны — `assets/background.jpg` (4928×3280). На постер 1080×1350
  `cover` берёт 53% ширины кадра; смещение `object-position: 64% 50%`
  ставит антенну в x 560–960 и оставляет левую часть под текст.
