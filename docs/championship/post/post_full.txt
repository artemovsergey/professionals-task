📌 Что нужно сделать:
• База данных PostgreSQL — 13 таблиц, 3НФ, триггеры, функции, процедура, аудит
• Backend и API — ASP.NET Core Web API, JWT аутентификация, RBAC, Swagger, коды ответов 200/201/204/400/401/403/404/409/429/500
• Десктоп-клиент — нативное приложение на C# / Avalonia (MVVM, без WebView), 8 экранов
• Веб-клиент — React + TypeScript + Vite, 9 страниц, SSE с опросом, экспорт PNG/CSV/PDF
• Модульные тесты — ровно 5 юнит-тестов desktop-клиента (xUnit)
• Документация — руководство пользователя, инструкция развёртывания, презентация, устное выступление

💡 Стек: PostgreSQL 15+, .NET 10, C#, React 19, TypeScript, xUnit, FluentAssertions.
