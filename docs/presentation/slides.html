Проблема и цель

Проблема

  • График ТО, заявки и склад ЗИП ведутся в разных таблицах
  • Невозможно посчитать простой оборудования и долю аварийных
  • Не видно, какая бригада чаще задерживает работы

Цель

  • База с ограничениями, которые не дают внести неправильные данные
  • Один REST API для двух клиентов
  • Аналитика: простои, рейтинг бригад, выполнение графика ТО

На экране: две колонки «проблема / цель».

Ограничения целостности

ВидПример в системе
UNIQUEлогин, инвентарный номер, артикул, номер заявки
CHECKхронология дат, критичность 1…5, формат номера Z-YYYY-XXXX
Перечислениястатусы оборудования, заявки и приоритет заданы типами базы
ON DELETEграфик удаляется каскадом, справочники защищены RESTRICT
Вычисляемые полястоимость = количество × цена, простой считает функция
  • Ошибка из базы доходит до клиента понятным текстом с кодом, а не как «500»
  • Проверяется скриптом db/verify.sql: каждая строка отчёта — отдельная проверка

На экране: DBeaver, вкладка «Ограничения» таблицы equipment.

Desktop-клиент

Мастер работает в восьми окнах: авторизация, дашборд, оборудование, график ТО, заявки, бригады, материалы, отчёты.

  • Нативный интерфейс на Avalonia — без встраивания веб-страниц
  • Индикатор связи, всплывающие сообщения, модальные окна ошибок
  • Работа без сети: показываются последние загруженные данные, операции складываются в очередь и уходят на сервер сами, как только связь вернётся
  • Локальный журнал: %LOCALAPPDATA%/ToirProf/logs/client.log

На экране: окно «Заявки» с выбранной заявкой и историей изменений.

Web-клиент: сводка и обновления

  • Шесть KPI-карточек: заявки, средний простой, доля аварийных, выполнение плана ТО, списание, цехи
  • Круговая, столбчатая и линейная диаграммы, топ-5 единиц по простою, последние заявки
  • Обновление в реальном времени через Server-Sent Events, а если поток недоступен — резервный опрос раз в минуту с переподключением

Индикатор в шапке:

SSE данные приходят потоком

Опрос поток недоступен, данные забираются раз в 60 секунд

Нет связи сервер недоступен, показаны последние загруженные данные

На экране: дашборд с индикатором SSE.
