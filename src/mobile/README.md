# Mobile-клиент

Приложение на **React Native**. Минимум **3 экрана**:

1. Вход / регистрация
2. Список задач
3. Создание задачи

**Требования:** создание, редактирование, отметка выполнения и удаление задачи; авторизация с сохранением токена между запусками; приложение запускается на реальном устройстве или эмуляторе.

Скриншоты экранов положите в репозиторий — папка `screenshots/` или рядом с этим README.

Приложение работает с тем же API, что и web- и desktop-клиенты.
