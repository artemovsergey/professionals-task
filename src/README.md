# Папка `src/`

Здесь будет лежать ваш код. Структура в репозитории **этого задания** — пример и подсказка, копировать её один в один не обязательно. Главное, чтобы было понятно, где что лежит.

| Папка | Что в ней должно быть |
|---|---|
| `api/` | Backend: обработчики запросов, работа с базой данных, авторизация |
| `web/` | Web-клиент: страницы, компоненты, стили, скрипты сборки |
| `desktop/` | Desktop-клиент: нативный интерфейс, логика, сборка |
| `mobile/` | Mobile-клиент на React Native: экраны, навигация, работа с API |

## Рекомендации

- **Клиенты не содержат бизнес-логики и не ходят в базу напрямую** — только через общий API.
- В каждой части есть файл с инструкцией по запуску либо инструкция описана в корневом `README.md`.
- Секреты и токены не коммитятся — используйте переменные окружения и `.env` в `.gitignore`.
- Код, который не относится к заданию, в репозиторий не попадает.
