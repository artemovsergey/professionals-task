# Backend и API

Один общий REST API для web-, desktop- и mobile-клиентов. Отдельных бэкендов не нужно.

**Стек:** .NET (ASP.NET Core), Node.js (Express / NestJS), Python (FastAPI / Flask).

**Что реализовать:** регистрация и вход, выдача токена, CRUD задач, отметка выполнения, сводка, фильтры и поиск, единый формат ответа, корректные HTTP-коды, логирование операций.

Спецификация — [`../../api/openapi.yaml`](../api/openapi.yaml). Коллекция для проверки — [`../../postman/Professionals-Task.postman_collection.json`](../postman/Professionals-Task.postman_collection.json).

Схема базы данных — [`../../db/schema.sql`](../db/schema.sql).
