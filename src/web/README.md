# Веб-клиент ТОиР-Проф

Клиент руководителя: дашборд, аналитика, реестры и справочники. Собран на
React 19 + TypeScript + Vite, тёмная тема в единых токенах.

## Запуск

```bash
cd src/web
npm install
npm run dev
```

Клиент поднимается на `http://localhost:5173` и проксирует `/api` на
`http://localhost:5080`. Адрес API можно переопределить переменной
окружения `VITE_API_TARGET` — это нужно, если API поднят не на этой машине.

Сборка и проверка типов:

```bash
npm run build
```

## Разделы

| Раздел | Адрес | Кому доступен | Что показывает |
|--------|-------|---------------|----------------|
| Дашборд руководителя | `/` | все | 6 KPI-карточек, круговая, столбчатая и линейная диаграммы, топ-5 единиц по простою, выполнение графика ТО, последние заявки |
| Аналитика | `/analytics` | ADMIN, MANAGER | панель фильтров и пять блоков: сводка по заявкам, анализ простоев, расход материалов, выполнение графика ТО, рейтинг бригад |
| Оборудование | `/equipment` | все | реестр с поиском, фильтрами по цеху/статусу/критичности, пагинацией |
| График ТО | `/schedule` | все | плановые работы за период, отметка выполнения и возврат в план |
| Заявки | `/work-orders` | все | реестр заявок с сортировкой и пагинацией, карточка с назначением бригады, стартом, завершением и списанием материалов |
| Бригады | `/crews` | ADMIN, MANAGER | реестр бригад с рейтингом, карточка с составом и загрузкой |
| Материалы и ЗИП | `/materials` | ADMIN, MANAGER | справочник, дефицитные позиции, приход на склад |
| Пользователи | `/users` | ADMIN | профиль текущего пользователя и сводный состав сотрудников по бригадам |

## Учётные записи для проверки

- `admin` / `Admin123!` — администратор, видит все разделы;
- `manager` / `Manager123!` — руководитель, без справочника пользователей;
- `master` / `Master123!` — мастер, только реестры и дашборд.

## Обновление в реальном времени

Дашборд получает сводку по Server-Sent Events из `/api/dashboard/events`.
Токен передаётся параметром `access_token`: `EventSource` не умеет добавлять
заголовки, а обработчик JWT по умолчанию читает токен из запроса.

Если поток не отвечает, клиент переходит на резервный опрос раз в 60 секунд,
а после обрыва переподключается с экспоненциальной задержкой от 1 до 30
секунд. Текущий режим показывает индикатор в верхней панели: `SSE`,
`Опрос` или `Нет связи`.

## Экспорт

Блоки аналитики выгружаются в CSV, PNG и PDF, страница печатается кнопкой
«Печать страницы». Правила `@media print` в `src/styles/components.css`
прячут меню, шапку и кнопки, поэтому в печать попадает только содержимое
разделов.

## Структура

```
src/
  api/          типы, HTTP-обёртка, адреса эндпоинтов
  auth/         контекст авторизации
  components/   таблица, карточки, диаграммы, toast, меню экспорта
  hooks/        загрузка данных, поток событий, экспорт, статус соединения
  layout/       оболочка с меню и верхней панелью
  pages/        экраны
  styles/       токены темы и стили компонентов
  utils/        форматирование чисел, денег и дат
```
