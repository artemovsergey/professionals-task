# Web-клиент

Сайт, который работает в браузере. Минимум **3–4 экрана**:

1. Регистрация / вход
2. Список задач с фильтрами и поиском
3. Создание и редактирование задачи
4. Сводка по задачам

**Требования:** адаптив от 360 px до 1920 px, пагинация или бесконечная подгрузка, состояния загрузки и «ничего не найдено», понятные сообщения об ошибках.

**Стек:** HTML + CSS + JavaScript либо React.

Данные не хранятся в браузере отдельно — всё приходит из общего API.
