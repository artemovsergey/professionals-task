# Desktop-клиент

Настольное приложение для Windows, Linux или macOS. Минимум **3–4 экрана**: вход, список задач, карточка задачи, сводка.

> **Это должно быть настольное приложение. Оборачивать web-страницу в окно Electron и считать это desktop-разработкой нельзя — за этот раздел снимут все баллы.**

**Стек:** C# / Avalonia, Python / PyQt, Electron (только с нативным интерфейсом, без вставки web-страницы).

Приложение работает с тем же API, что и web- и mobile-клиенты. У всех клиентов одна и та же база данных и один backend.
